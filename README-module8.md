# Домашнє завдання - Модуль 8

Три навчальні HTML-сторінки зроблені на основі локального зразка `index.html`. Основна сторінка-зразок не змінювалася.

## Сторінки

- `hobby.html` - сторінка про захоплення створенням вебсайтів.
- `portfolio.html` - семантичне портфоліо з розділами про мене, навички та проєкти.
- `course-registration.html` - навчальна форма з полями та вбудованою перевіркою HTML.
- `css/homework.css` - спільне адаптивне оформлення сторінок.
- `assets/coding-hobby.svg` - локальна ілюстрація з текстом `alt` у HTML.

## Пояснення тегів

- `head` містить метадані сторінки, її назву, кодування та підключення стилів. Цей вміст не є основною частиною сторінки, яку читає користувач.
- `body` містить видимий вміст сторінки.
- `h1` задає головний заголовок сторінки; на сторінці він один.
- `a` створює посилання на іншу сторінку, сайт або розділ за його `id`.
- `img` показує зображення. Атрибут `alt` описує його для скринрідерів і на випадок, якщо зображення не завантажиться.

## Семантичні теги

- `header` містить вступну частину сторінки або шапку сайту.
- `nav` позначає блок навігаційних посилань.
- `main` містить головний зміст сторінки.
- `section` групує зміст за окремою темою та має заголовок.
- `article` позначає самостійний матеріал, наприклад картку проєкту.
- `footer` містить завершальну інформацію, наприклад контакти.
- `div` є нейтральним контейнером без власного семантичного значення; використаний для групування карток і полів.
- `span` є нейтральним рядковим контейнером; використаний для короткої позначки всередині тексту.

## Додаткова практика з помилками

Додаткова практика в умові необов’язкова. Щоб виконати саме її без AI у Cursor, можна по черзі внести й одразу виправити такі помилки, не зберігаючи їх у фінальній версії:

1. **Невідповідність `label` та `id`:** тимчасово зміни `for="email"` на `for="email-address"`. Виправлення: поверни `for="email"`, щоб воно збігалося з `id="email"`.
2. **Різні `name` для radio-кнопок:** тимчасово задай другій radio-кнопці `name="studyFormat"`. Виправлення: для обох варіантів поверни `name="format"`.
3. **Неправильний тип email-поля:** тимчасово заміни `type="email"` на `type="text"`. Виправлення: поверни `type="email"`, щоб браузер перевіряв формат адреси.

Ці помилки наведені як інструкція для ручної практики, а не як уже виконані тобою виправлення.

Форма демонстраційна: JavaScript зупиняє стандартне надсилання, тому дані не відправляються на сервер і не зберігаються.

## Перевірка

Відкрийте сторінки у браузері. Щоб побачити валідацію, відкрийте `course-registration.html` і натисніть «Зареєструватися» з порожніми обов’язковими полями. Браузер підсвітить перше поле, яке потрібно заповнити.
